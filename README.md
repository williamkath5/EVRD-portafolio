# Portafolio — Rediseño del modelo ECO-RED Normalista

Página del portafolio digital que presenta el rediseño del modelo de evaluación de Recursos Educativos Digitales (RED) **ECO-RED Normalista**: referentes LORI y COdA, limitaciones identificadas, dimensiones e indicadores, escala de valoración, instrumento completo, metodología y referencias (APA 7.ª ed.).

- **Autor:** William Darío Gómez Vega
- **Programa:** Especialización en Aplicación de TIC para la Enseñanza — CVUDES / Universidad de Santander (UDES)
- **Módulo:** Evaluación de Recursos Educativos Digitales — Entregable 2
- **Institución de contexto:** Escuela Normal Superior Francisco de Paula Santander, Málaga, Santander (Colombia)
